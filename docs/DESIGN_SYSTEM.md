# Design System

The default UI is dark mode with a premium restaurant operations style.

## Palette

- Background start: `#070B12`
- Background end: `#101827`
- Glass card: `#151C28`
- Secondary glass: `#1B2432`
- Border: `#2C374A`
- Gold: `#D6A84F`
- Gold light: `#F0C978`
- Green: `#22C55E`
- Red: `#EF4444`
- Orange: `#F59E0B`
- Cyan: `#06B6D4`
- Purple: `#A855F7`
- Text primary: `#F8FAFC`
- Text secondary: `#A7B0C0`
- Text muted: `#64748B`

## UX Principles

- Full RTL layout through `LocalLayoutDirection`.
- Persian labels throughout the visible app.
- Jalali-style date display.
- Persian digit and comma formatting.
- Rounded glass cards with subtle border and dark gradient background.
- Gold is used for primary actions and financial emphasis.
- Cyan, green, red, orange, and purple communicate secondary statuses.
